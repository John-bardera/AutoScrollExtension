# Auto Scroll

**長文読書のための自動スクロール Chrome 拡張(Manifest V3、ビルド不要・純粋 JS)。**

「Alt+S を押すだけで、アクティブタブが一定速度で静かに流れ始める」——長い記事・ドキュメント・技術ブログを読むとき、スクロール操作から手を離し、読むことに集中できます。

## この拡張の売り

- **ワンキーで開始/停止**: Alt+S(chrome.commands なので好みのキーに変更可能)
- **速度がブレない**: rAF ループで `速度 × 経過時間` を積算し、小数の残りを次フレームに持ち越して**整数 px でのみ**スクロール。丸め誤差が溜まらず、低速度でもガタつきません
- **タブを追従**: スクロールは常に「アクティブウィンドウのアクティブタブ」のみ。タブを切り替えると旧タブは停止し、**切り替え先で同じ速度で即時再開**(content script 注入待ちの再送つきなので、直前まで開いていなかったタブでも大丈夫)
- **末尾でも止まらない**: ページ最下部に到達しても停止しません。上にスクロールして戻せば、そこから再び流れ始めます
- **速度の永続化**: 設定は `chrome.storage.sync` に保存。ブラウザを再起動しても同じ速度で再開
- **EN / JA**: 表示言語(既定 English)を popup から切替可能。オーバーレイ表示も切り替わります

## 機能詳細

| 機能 | 詳細 |
| --- | --- |
| トグル | Alt+S(または popup の「Start/Stop」ボタン) |
| 速度 | 10 〜 1000 px/s、既定 60。popup のスライダー/数値入力で調整。実行中のスクロールへ即時反映 |
| キーボード速度調整 | スクロール中のみ ↑↓ で ±10 px/s。テキスト入力中・修飾キー(Ctrl/Cmd/Alt)併用時は無視。境界値(10/1000)でクランプ |
| 速度オーバーレイ | 開始・停止・速度変更時に画面右下へ数秒表示 |
| タブ追従 | tabs.onActivated / windows.onFocusChanged / tabs.onUpdated を監視。SW がアイドル停止しても実行状態を `storage.session` に退避して復元 |
| 拡張更新後の再注入 | 更新・再読込後に、既に開いていた全タブ(http/https/file)へ自動で content script を再注入(v0.1.3 以降) |
| 言語 | English(既定)/ 日本語 |

## インストール

### ZIP(Release)から導入する場合

1. [Releases](https://github.com/John-bardera/AutoScrollExtension/releases) の最新版から ZIP をダウンロード
2. ZIP を任意の場所に展開する(ディレクトリはそのまま保持)
3. 下記「ブラウザへ読み込む」へ進む

### ソースから導入する場合

```bash
git clone https://github.com/John-bardera/AutoScrollExtension.git
```

そのまま下記「ブラウザへ読み込む」へ進みます。

### ブラウザへ読み込む

1. Chrome / Arc で `chrome://extensions`(Arc では `arc://extensions`)を開く
2. 右上の「デベロッパーモード」を有効にする
3. 「パッケージ化されていない拡張機能を読み込む」で、`manifest.json` のあるフォルダを選択
4. ツールバーのピン留めから Auto Scroll を固定(任意)

> **file:// のページで使う場合**: 拡張の「詳細」から「ファイルの URL へのアクセスを許可」を
> 有効にしてください。

### 更新するとき

ZIP なら展開し直して同じフォルダを読み込み直す、ソースなら `git pull` した後、
`chrome://extensions` の拡張カードにある「更新」ボタン(↻)を押してください。
v0.1.3 以降は、更新時に**すでに開いていたページにも自動で再注入**されるため、
そのまま全タブで使えます。万一効かないページがあれば、そのページを再読込してください。

## 使い方

1. 長いページを開き、**Alt+S** でスクロール開始
2. 速度は popup のスライダー/数値入力、または ↑↓ キーで調整
   (↑↓ はスクロール有効中のみ有効。テキスト入力中は無視される)
3. もう一度 **Alt+S** で停止
4. 表示言語は popup の「Language」から選択

## トラブルシューティング(Arc)

- **ショートカットが効かない**: Arc には `chrome.commands` のショートカットが効かなくなる既知の問題があります。`arc://extensions/shortcuts` で別キー(例: Ctrl+Shift+S)に変更するか、Arc を再起動してください。popup の「Start/Stop」ボタンは常に使えます
- **特定のタブで効かない**: 拡張の「詳細」→ サイトへのアクセスが「すべてのサイト」になっているか、またタブが拡張を有効にしたプロファイルと同じ Space かを確認してください(Arc の Spaces はプロファイル単位で拡張を持てます)
- **診断**: `arc://extensions` → Auto Scroll → service worker でコンソールを開くと、`[AutoScroll]` プレフィックスの経路ログを観察できます

## 構成

| ファイル | 役割 |
| --- | --- |
| `manifest.json` | MV3 マニフェスト。Alt+S コマンド定義 |
| `i18n.js` | 表示言語カタログ(EN/JA)。content / popup で共有 |
| `content.js` | スクロール本体。rAF ループと小数残差による速度安定化 |
| `background.js` | Service Worker。ON/OFF とスクロール中タブの管理、タブ追従、全タブ再注入、設定の永続化 |
| `popup.html` / `popup.css` / `popup.js` | 速度・言語の設定 UI |
| `test-page.html` | 手動動作確認用ページ |
