# Auto Scroll

長文の読書を支援する Chrome 拡張機能(Manifest V3)。アクティブタブを自動スクロールします。

設計書: `docs/superpowers/specs/2026-11-02-auto-scroll-extension-design.md`

## 機能

- **トグル**: Alt+S(chrome.commands、Chrome のショートカット設定で変更可能)
- **速度**: 10 〜 1000 px/s(既定 60)。popup のスライダー/数値入力、またはスクロール中の ↑↓ キー(±10 px/s)で調整
- **速度の永続化**: `chrome.storage.sync` に保存。ブラウザ再起動後も同じ速度で再開
- **タブ追従**: スクロールは常に「アクティブウィンドウのアクティブタブ」のみ。タブを切り替えると旧タブは停止し、切り替え先は popup の設定に従う
  - **続ける(既定)**: 切り替え先でも同じ速度で即時再開(content script の注入完了を待つ再送つき)
  - **停止する**: 切り替え先では停止。Alt+S で再開
- **末尾では停止しない**: ページ最下部に到達しても停止せず、ユーザーが上へ戻ればそこから再び流れる
- **言語選択**: popup で日本語 / English を選択可能(storage.sync に永続化)
- **速度オーバーレイ**: 開始・停止・速度変更時に画面右下に一瞬表示

## インストール

### GitHub から導入する場合

1. [Releases](https://github.com/John-bardera/AutoScrollExtension/releases) があれば ZIP をダウンロード、なければリポジトリをクローンする:

   ```bash
   git clone https://github.com/John-bardera/AutoScrollExtension.git
   ```

2. ZIP の場合は任意の場所に展開する
3. 下記「デベロッパーモードで読み込む」へ進む

> 更新を取り込むときは、クローンしたディレクトリで `git pull` した後、
> `chrome://extensions` の拡張カードにある「更新」ボタン(↻)を押してください。

### デベロッパーモードで読み込む

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパーモード」を有効にする
3. 「パッケージ化されていない拡張機能を読み込む」でこのディレクトリ(`manifest.json` のあるフォルダ)を選択
4. ツールバーのピン留めから Auto Scroll を固定(任意)

> **file:// で確認する場合**: `test-page.html` をローカルファイルとして開くときは、
> `chrome://extensions` の Auto Scroll「詳細」から「ファイルの URL へのアクセスを許可」を
> 有効にする必要があります。

## 使い方

1. 長いページを開き、**Alt+S** でスクロール開始
2. 速度は popup のスライダー/数値入力、または ↑↓ キーで調整
   (↑↓ はスクロール有効中のみ有効。テキスト入力中は無視される)
3. もう一度 **Alt+S** で停止
4. タブ切替時の挙動は popup の「タブ切替時の挙動」で変更可能

## 動作確認チェックリスト

`test-page.html` をブラウザで開いて確認する。

1. [ ] `chrome://extensions` から拡張を読み込み、エラーが出ない
2. [ ] `test-page.html` で Alt+S を押すとスクロールが始まり、右下にオーバーレイが出る
3. [ ] もう一度 Alt+S で停止する
4. [ ] popup のスライダーを動かすと実行中のスクロール速度が即時変わる
5. [ ] ↑↓ キーで速度が ±10 px/s ずつ変わり、オーバーレイに表示される
6. [ ] ↑↓ を押し続けると速度が 10 と 1000 で止まる(クランプ)
7. [ ] テキスト入力欄にフォーカス中は ↑↓ が無視される
8. [ ] ページ末尾に達しても停止せず、上へ戻すとそこから再び流れる
9. [ ] 末尾で停止した状態にならない(再開操作が不要)
10. [ ] スクロール中に別タブへ切り替えると旧タブが停止し、設定「続ける」なら切り替え先で同速で開始する(直前まで開いていなかったタブでも)
11. [ ] 設定「停止する」にすると、切り替え先では停止する
12. [ ] `chrome://` ページや新規タブで Alt+S を押してもエラーが出ない(何も起きない)
13. [ ] 速度を変更 → ブラウザ再起動 → popup を開くと、変更した速度が保持されている
14. [ ] popup の「開始/停止」ボタンで Alt+S と同じトグルが動く
15. [ ] 30 秒以上スクロールさせてから(Service Worker が停止するのを待ってから)Alt+S で停止できる
16. [ ] スクロール中にウィンドウのフォーカスを別ウィンドウへ移すと停止する
17. [ ] スクロール中のタブを再読み込みしても、読み込み完了後に再びスクロールが始まる
18. [ ] popup の言語を English にすると popup とオーバーレイ表示が英語になり、再起動後も保持される

## 構成

| ファイル | 役割 |
| --- | --- |
| `manifest.json` | MV3 マニフェスト。Alt+S コマンド定義 |
| `i18n.js` | 表示言語カタログ(JA/EN)。content / popup で共有 |
| `content.js` | スクロール本体。rAF ループと小数残差による速度安定化 |
| `background.js` | Service Worker。ON/OFF とスクロール中タブの管理、タブ追従、設定の永続化 |
| `popup.html` / `popup.css` / `popup.js` | 速度・挙動・言語の設定 UI |
| `test-page.html` | 手動動作確認用ページ |
