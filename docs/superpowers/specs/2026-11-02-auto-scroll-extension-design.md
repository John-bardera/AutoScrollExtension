# 自動スクロール Chrome 拡張機能 設計書

日付: 2026-11-02
ディレクトリ: `/home/john/programming/auto-scroll-extension/`

## 目的

長文の読書支援のための、ブラウザ自動スクロール Chrome 拡張機能 (Manifest V3)。

## 要件(確定済み)

1. ブラウザの自動スクロール機能
2. ON/OFF はクリック(拡張アイコン)とキー(デフォルト Alt+S、chrome://extensions/shortcuts で変更可)の両方で容易に操作可能
3. スクロールが自然(滑らかで速度が揺れない)
4. スクロール速度を調整可能
   - ポップアップ上のスライダーと数値入力
   - スクロール有効中のみ、設定されたキー(デフォルト: ↑/↓)での微調整
5. 速度設定は永続化し、ブラウザ再起動後も前回の速度で再開する
6. スクロール対象は常に「アクティブウィンドウのアクティブタブ」のみ
   - タブ切替(Ctrl+Tab 等)時、元のタブは停止する
   - 移動先タブは「即時に同速で開始」または「一旦停止」を選択可能(設定、デフォルト: 即時開始)
   - 「一旦停止」選択時、移動先で Alt+S を押せば前回速度で開始する

## スコープ外

- マウスカーソル下の内部スクロール領域(iframe・ overflow 枠)のスクロール。ページ全体(メインスクロール)のみ対象
- タブを完全に閉じた場合の継続(そのタブの処理は消滅するため不可能)

## アーキテクチャ

Manifest V3。全ページに常駐コンテンツスクリプトを注入し、background Service Worker がメッセージでON/OFFを中継する方式。

### ファイル構成

| ファイル | 役割 |
|---|---|
| `manifest.json` | MV3定義。commands (toggle: Alt+S)、permissions: storage / tabs、content_scripts (全ページ、document_idle) |
| `background.js` | Service Worker。Alt+S コマンド受信→アクティブタブへトグル命令。tabs.onActivated 検知→旧タブへ停止、新タブへ開始(設定に応じ)。tabs.onRemoved 検知→状態掃除。popup からのメッセージ中継 |
| `content.js` | スクロール本体(後述)。キーボード速度調整(↑↓)、末尾自動停止、速度オーバーレイ表示 |
| `popup.html` / `popup.js` / `popup.css` | スライダー+数値入力(10〜1000 px/s、初期値 60)、トグルボタン、タブ切替時の挙動選択 |
| `test-page.html` | 動作確認用の長文ローカルページ |
| `README.md` | インストール手順(デベロッパーモード→パッケージ化されていない拡張機能を読み込み)と手動確認チェックリスト |

### 状態とデータフロー

- 設定(速度、タブ切替時の挙動)は `chrome.storage.sync` に永続化。デフォルト速度 60 px/s、デフォルト挙動「即時開始」
- 「スクロール中かどうか」の実行状態は background 側でアクティブタブ ID 単位で管理(メモリ上のみ。永続化不要)
- ON/OFF の単一の真実源は background。popup と content は background に問い合わせて現在状態と速度を取得する

### スクロールの自然さ(content.js)

- `requestAnimationFrame` ループで毎フレーム `speed × dt` px を加算
- 加算値は小数のまま残差として蓄積し、`window.scrollBy` は整数 px でのみ発行(丸め誤差が溜まらず、長時間でも速度が揺れない)
- ページ末尾(scrollHeight 到達)で自動停止し、background に状態を報告
- スクロール位置がユーザーの手動操作(ホイール等)で動いても継続(手動で戻されたらその位置から再開)

### タブ切替の追従(background.js)

- `tabs.onActivated` で旧アクティブタブに「停止」を送信
- 新アクティブタブに設定に応じて「開始(前回速度)」または何も送らない
- バックグラウンドタブはスクロールしないため、Chrome の rAF/タイマー抑制の問題は原理的に発生しない

### キーボード操作(content.js 内)

- ↑/↓(設定可能)で速度 ±10 px/s、範囲は 10〜1000 px/s。変更は storage.sync に即時保存し、オーバーレイに一時表示
- テキスト入力中(input/textarea/contentEditable フォーカス時)は無視
- トグルキー(Alt+S)は chrome.commands 経由で background が受け取るため、content 側の実装不要。フォーカス状態に依存せず動作する

## エラー処理

- メッセージ送信先タブが既に閉じている場合の例外は握り潰さず握りつつ無視(競合状態として正常)
- content script が注入されていないページ(chrome:// ページ等)への送信失敗は無視
- storage 読み込み失敗時はデフォルト値にフォールバック

## テスト方針

- `test-page.html` による手動確認。チェックリスト: Alt+S トグル、↑↓での速度変化とオーバーレイ、末尾自動停止、タブ切替での両挙動、ポップアップ設定反映、ブラウザ再起動後の速度記憶
- 自動テストは規模に対し過剰なため設けない(手動チェックリストを README に明記)
